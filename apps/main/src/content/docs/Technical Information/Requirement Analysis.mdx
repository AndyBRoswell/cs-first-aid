<section>
  本项目自 2021 年 2 月 8 日创建以来已连续多年不断修订。2025 年，在决定进一步扩充项目内容（当时仍为单体`README.md`）时，发现项目存在若干问题：
  - 已积累了一定数量的包括课程、教科书与参考资料的元信息等多方面的内容，手工维护繁琐，内容的复核、表示课程与学习资料间的关联、元信息的更新等均存在实质不便。
  - 总字数已较多，单一 README 长文档的阅读也许已较为困难。

  因而决定对本项目进行重构。

  目前已知下列修订将进行：
  - 降低软工方向数学必修部分的难度
  - 同步学习资料（书籍、文档等）的最新版次
  - 引入新课程与新学习资料
    - 考虑当下就业情况，本项目将全面 ECE/EECS 化
    - 新增数学与 ECE/EECS 选修课
  - 添加参考学习路线
  - 按读者水平为课程内容分层
  - 展示课程先修关系
  - 新增近期积累的实用建议
  - 按章节添加 FAQ
  - 增强可读性
</section>
