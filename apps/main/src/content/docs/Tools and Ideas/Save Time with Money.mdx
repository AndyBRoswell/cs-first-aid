---
title: 用钱换时间
author: AndyBRoswell
---

对于能够提升学习效率的物件，确实有需要就不要犹豫，尽快买。不要老是等什么 618、双十一、双十二之类的活动。
- 现在很多商品，特别是数码产品，在这些活动之前经常悄咪咪涨价，活动开始再降下来，制造大力度打折的假象，进而使得实际上在购物节期间价格并不便宜多少。
  - 2025 年以来，数码产品迎来了大规模涨价。这些购物节期间电子产品的降价幅度基本上很小了。
- 软件上想省钱的，可以多找找免费软件，特别是开源且免费的。
  - [Visual Studio Community](https://visualstudio.microsoft.com/vs/community/)。**对个人开发者、学生、开源贡献者和小型企业免费开放**。另外两个版本 Professional 和 Enterprise 都是收费的。
    - Windows 平台的 VS 主要使用 C# 开发，GUI 框架为 WPF（也有一部分 WinForms 或老旧的 C++ GUI 部件，猜测使用了 MFC）。大量实践表明，在 Windows 系统中，其运行速度显著快于 JetBrains 系列 IDE（Java / Kotlin + Swing）。美中不足的是，Visual Studio 不支持在 Linux 系统中运行。
      - SQL Server [已经可以运行在 Linux 上](https://learn.microsoft.com/en-us/sql/linux/sql-server-linux-overview)。可能在未来的某一天，我们也会等来 Visual Studio 或 Microsoft Office 的原生 Linux 版本。但我个人感觉概率不大。
    - Visual Studio for Mac 已经停止开发，最后一个版本的支持已于 2024 年 8 月 31 日结束。[详情](https://devblogs.microsoft.com/visualstudio/visual-studio-for-mac-retirement-announcement/)
    - 请及时升级到 Visual Studio 2022 或更新的版本。因为 VS2022 是 64 位的，允许使用超过 4 GB 的内存，并提升运行于 64 位环境下的性能，有利于顺利打开超大规模的解决方案（solution，VS 里面一个 solution 包含若干个工程或项目，也就是 project，很多 IDE 都只有 project 的概念）。另外，代码补全的改进也获得了较多来自开发者的好评。
- 对于一门课，**仅学习一本教材但需要多本参考书或其它参考资料是很常见的。
  - 之前我认为：没有必要省去这些买参考资料的钱，即便这些资料只被自己偶然查阅。但我发现，结合当前的经济下行背景，书的数目多起来了以后，并不能算是一笔不高的开支。我目前其实也没有太多好办法，只能尽量为大家去找更多的免费或低价书籍。当然，如果经济条件比较好，我还是继续建议你不必节省这一笔预算。

不要去抢那些零碎的优惠。比如：
- 学校附近某个奶茶店开张，为了几块十来块的优惠去排队一整个下午，真的很没有必要。况且，奶茶喝多了也对身体不好。
- 笔者做志愿活动期间（18Q4），看到有商家在某小区门口搞活动，奖品无非是粽子或者其它一些简单的吃的，或者一二十块这种程度的返现，结果那小区里外好多人（特别是老人家）就在那里挤着来参加，折腾了一上午。真替他们觉得累。
- “瓜分`\d+(?:\.\d+)?`亿”？收皮啦你！一堆中高端手机都跑不流畅的毒瘤应用成天搞这种浪费时间的狗屁任务，一个签到能跳好几个页面，分币不给几个也好意思叫人玩垃圾小游戏报废整整几分钟，就非得这么跟用户体验过不去？如此巴望着把大家的时间能占一点是一点，怎么好像不这么死缠烂打拖用户时间就立刻欠八辈子高利贷一样？

经济条件不错的，不建议勤工俭学。
- 与志愿活动不同。勤工俭学会有少量的工资（如，每月 400 块），因此不可以算作志愿活动。
- 实在有闲的情况除外（按照现在的卷情，已经几乎不可能，除非是有条件继承资产与人脉的各种二代）。
  - 同样地，考虑大家的经济压力，确实拿不出钱买 PC 或存储设备，就去干吧。
    - 在校外打工的收入通常高得多，但一般的兼职太多骗子了。如果去实习，低年级学生恐怕不一定被对口岗位录取（至少不是优先录取），特别是履历不是相当拔尖的时候。假如只能找到摇奶茶这种所谓的“工作”，不仅没有技术含量、不为自己或他人带来多少正面作用，没几个子儿的同时又累死累活，还不如不去。
