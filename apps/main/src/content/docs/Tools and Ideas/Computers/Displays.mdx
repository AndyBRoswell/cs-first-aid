  # 根据视力估计所需的 PPI
  记最小角分辨率（MAR）为 $\theta$ $"arcmin"$，视力（UCVA / BCVA）为 $V$（小数记法），则
  $$
  \theta=1/V
  $$
  设观看距离为 $d$，像素间距（pixel pitch）为 $p$，我们有
  $$
  tan(1/2 \theta)=(1/2 p)/d
  $$
  即
  $$
  p=2d tan(1/2 \theta)
  $$
  设单位长度为 $l$，则像素密度
  $$
  \rho=l/p
  $$
  联立得
  $$
  \rho=l/(2d tan(\pi/21600V))
  $$
  代入
  $$
  l=1\thinsp"in"
  $$
  则 $\rho$为 PPI。
  需要注意的是，这只是一个估计值。显示器的像素密度超过这个值，并不代表完全没有用：
  - 一般地，人眼对点、线、周期纹理、锯齿、等的敏感度不同。
  - 子像素布局<Cite mangled_references={Displays.mangled_references} cite_items={ [ { condition: { filter: m => util.ieq(m.title, 'Optimal Rendering for Colour Matrix Displays'), options: { count: 1 } }, label: 'figure', locator: 1, } ] }/>（如 RGB stripe、Pentile）会对实际感知产生可见影响。
  - 对比度、观看角度、软件层面的字体抗锯齿等因素会产生较明显的影响。

      ### 示例
      对于一台 17.3" 的笔记本，其显示比例一般为 16:9（具有该宽高比的屏幕更大的笔记本往往难以装入常见的背包）。设其分辨率为 1080p，则其 PPI 为
      $$
      \rho=(\sqrt(w^2+h^2)/d)|_(w=1920" ""px",h=1080\thinsp"px",d=17.3\thinsp"in")\approx 127.3\thinsp"PPI"
