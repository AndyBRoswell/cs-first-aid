主流云厂商提供了一些长期免费（always free）的服务。
- [Azure](https://azure.microsoft.com/en-in/pricing/free-services/)
- [AWS](https://aws.amazon.com/free)
- [GCP](https://cloud.google.com/free)
  - Google Developer Program 订阅[每月发放免费的点数](https://developers.google.com/profile/help/faq#premium-membership-benefits)，可用于 GCP 或 Google AI Studio。例如，每月约 20 欧元的 Premium 订阅同时包含 Google AI Pro，因而在 [Gemini Web 端](https://gemini.google.com/)也提供了更多的免费次数，同时包含 5 TB 的 GDrive 存储容量。
- [Oracle Cloud](https://www.oracle.com/cloud/free/)
- [IBM Cloud](https://www.ibm.com/cloud/free)
- [DigitalOcean](https://www.digitalocean.com/pricing)

我已注意到近年来云厂商提供的免费云服务正逐步减少。
