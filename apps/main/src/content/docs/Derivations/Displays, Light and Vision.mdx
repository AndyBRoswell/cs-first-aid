  # 视力
  记眼的最小角分辨率（MAR）为 $\theta$ $"arcmin"$，此时对应的视力（UCVA / BCVA）为 $V$（小数记法），则<Cite references={M} cite_items={[ { condition: 'ISO 8596:2017', label: 'section', locator: '3.3.1' } ] }/>
  $$
  \theta=1/V
  $$
  可见，当 $V=1.0$ 时，最小角分辨率为 1 角分（弧分）；若 $V=2.0$，则最小角分辨率为 0.5 角分。

  最小角分辨率由视标（optotype）测定。对于 E 视标，每一笔画的宽度代表角分辨率<Cite references={M} cite_items={[ { condition: 'GB/T 11533-2011', label: 'section', locator: '2.2' } ] }/>；对于 C 视标（Landolt 环），开口宽度或圆环宽度代表角分辨率。<Cite references={M} cite_items={[ { condition: 'ISO 8596:2017', label: 'figure', locator: 1 } ] }/>

  除了小数记法，还有别的记法来表示视力。例如，中国内地还采用五分记录（5-mark record）<Cite references={M} cite_items={[ { condition: 'GB/T 11533-2011', label: 'section', locator: '2.14' } ] }/>。其计算公式为
  $$
  L=5-lg \theta
  $$
  例如，4.0 代表 MAR 为 10 角分，5.0 代表 MAR 为 1 角分，5.3 代表 MAR 为 0.5 角分。
  英语区还采用 Snellen 分数<Cite references={M} cite_items={[ { condition: 'ISO 8596:2017', label: 'section', locator: '3.3.2' } ] }/>。其计算公式为
  $$
  V_"Sn"=D_"t"/D_"n"
  $$
  $V_"Sn"$、$D_"t"$ 和 $D_"n"$ 分别代表（不约分的）Snellen 分数、测试距离和标准距离。$V_"Sn"$ 的值和小数记法的值相等。比如，20/40 或 6/12 代表 2 角分，意即：受试者能在 20 英尺或 6 米远辨认的视标，正常人在 40 英尺或 12 米远就能辨认；20/8 或 6/2.4 代表 0.4 角分，意思是：受试者能在 20 英尺或 6 米远辨认的视标，正常人需要走近至 8 英尺或 2.4 米才能辨认。

  科研文献中，最常用的记法之一是 LogMAR。计算公式为<Cite references={M} cite_items={[ { condition: 'ISO 8596:2017', label: 'section', locator: '3.3.3' } ] }/>
  $$
  V=10^"-LogMAR"
  $$
  小数记法的 0.2、1.0、1.5 分别对应 LogMAR 记法的 +0.70、0、-0.20。
</section>

  # 像素密度
  设单位长度为 $l$，则像素密度
  $$
  \rho=l/p
  $$
  代入 $l=1\thinsp"in"$，则 $\rho$ 为每英寸像素（PPI）。代入 $l=1\thinsp"cm"$，则 $\rho$ 为每厘米像素（PPCM）。
  <section>
    ## 根据视力估计所需的像素密度
    设观看距离为 $d$，像素间距（pixel pitch）为 $p$，我们有
    $$
    tan(1/2 \theta)=(1/2 p)/d
    $$
    即
    $$
    p=2d tan(1/2 \theta)
    $$
    又有
    $$
    1\thinsp"arcmin"=1/180 \pi\times 1/60
    $$
    消去 $\theta$，得
    $$
    \rho=l/(2d tan(\pi/21600V))
    $$
    可见，所需的像素密度 $\rho$ 与视力 $V$ 及观看距离 $d$ 均有关。

    需要注意的是，这只是一个估计值。显示器的像素密度超过这个值，并不代表完全没有用：
    - 一般地，人眼对点、线、周期纹理、锯齿等的敏感度不同。
    - 子像素布局<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m.title, 'Optimal Rendering for Colour Matrix Displays'), options: { count: 1 } }, label: 'figure', locator: 1, } ]}/>（如 RGB stripe、Pentile）会对实际感知产生可见影响。
    - 对比度、观看角度、软件层面的字体抗锯齿等因素也会产生较明显的影响。
    - 双眼视力常常优于单眼视力。

    [此查找表](/tools-and-ideas/computers/displays#视力观看距离与-ppi-查找表)可用于按照视力与观看距离找到所需的显示设备 PPI。

  # 叠加原理
  设一个系统 $y=F(x)$ 的定义域为 $D$，$x$ 和 $y$ 分别代表该系统的输入（刺激）和输出（反应），且 $x$、$y$ 既可以是标量也可以是向量（矢量）。$\forall x_1,x_2\in D$，若总有：
  - 可加性（additivity）：$F(x_1+x_2)=F(x_1)+F(x_2)$
  - 齐次性（homogeneity）：$F(ax)=aF(x)$，其中 $a$ 是任意标量

  则该系统符合叠加原理（superposition principle）。可加性与齐次性合称线性性（linearity）。

  在一些特殊情况下，叠加原理会失效<Cite references={M} cite_items={[ { condition: { filter: m => m['collection-title']?.includes('OSE 6334') && /Introduction to nonlinear optics/.test(m.title) }, label: 'page', locator: 5 } ] }/><Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m.title, 'Roadmap on nonlinear optics–focus on Chinese research') }, label: 'page', locator: 1 } ] }/>。但在传统显示技术中，叠加原理通常是有效的。
</section>

    ## 辐射度量学的预备知识
    设一个电磁波波源累计发出的能量为 $Q$，$t$ 代表时间点。该波源在时间 $"\Delta"t$ 内共计发出了能量 $"\Delta"Q$，则该源在特定时刻的（瞬时）辐射通量（辐射功率）<Cite references={M} cite_items={[ { condition: 'PBRT', label: 'section', locator: '4.1.1' } ] }/>
    $$
    \Phi_"e"=\Phi_"e" (t)=lim_("\Delta" t\rightarrow 0) ("\Delta"Q/"\Delta"t)="d"Q/"d"t
    $$
    下标 $"e"$ 代表[辐射度量学](https://zh.wikipedia.org/wiki/%E8%BE%90%E5%B0%84%E5%BA%A6%E9%87%8F%E5%AD%A6)（Radiometry）的物理量<Cite references={M} cite_items={[ { condition: 'Rapport BIPM-2019/05', label: 'section', locator: '2' } ] }/>。

    在特定时刻，设 $A$ 代表曲面面积，$P$ 为曲面上的一点，$"d"A$ 为 包含 $P$ 的面积元，$"d"\Phi_"e" (P)$ 为该面积元接收或发出的来自各个方向的（瞬时）辐射功率（分别称为辐照度 $E_"e" (P)$、辐射出射度 $M_"e" (P)$，即：辐射功率的面密度），则<Cite references={M} cite_items={[ { condition: 'PBRT', label: 'equation', locator: '4.1' } ] }/><Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'radiant exitance') }, } ] }/>
    $$
    E_"e" (P)="d"\Phi_"e" (P)/"d"A
    $$
    $$
    M_"e" (P)="d"\Phi_"e" (P)/"d"A
    $$

    当波源为**点源**时，在某个方向 $\omega$（由单位向量表示）的辐强度（辐射功率的角密度）<Cite references={M} cite_items={[ { condition: 'PBRT', label: 'equation', locator: '4.2' } ] }/>
    $$
    I_"e" (\omega)="d"\Phi_"e" (\omega)/"d"\omega
    $$
    其中 $"d"\omega$ 为围绕该方向的微分立体角<Cite references={M} cite_items={[ { condition: { filter: m => m["collection-title"]?.includes('CS 184') && /Lecture/.test(m.title) && /Radiometry/.test(m.title) }, label: 'page', locator: '13' } ] }/>。

    实验表明，在不受强引力场影响的条件下、在没有吸收、散射或界面的各向同性均匀介质或真空中（下称“理想条件”），电磁波可以近似看作沿直线传播。其传播方向可以由射线表示。当电磁波为可见光时，这样的射线称为光线。

    电磁波不一定以垂直方向穿过曲面。设经过面积元 $"d"A$ 上的一点 $P$ 的法向量为 $n\vec$，波由方向 $\omega$ 射入。记 $\theta=\angle(n\vec,\omega)=\langle n\vec,\omega\rangle$ s.t. $\theta\in[0, 1/2 \pi)$。则沿 $\omega$ 方向的辐照度为
    $$
    "d"E_("e"\perp) (P,\omega)="d"E_"e" (P,\omega)/cos\theta
    $$
    换言之，面积元 $"d"A$ 在方向 $\omega$ 本应获得辐照度 $"d"E_("e"\perp) (P,\omega)$，这需要令该面积元 $"d"A$ 垂直于方向 $\omega$ 即 $\theta=0$ 时才能获得；如果它与辐射的入射方向 $\omega$ 不垂直，即 $\theta>0$，它在这个方向 $\omega$ 就只获得了更少的辐照度 $"d"E_"e" (P,\omega) = "d"E_("e"\perp) (P,\omega)cos\theta$。典例：在日常生活中，太阳光可视为平行光；只有阳光垂直入射到太阳能板，这块太阳能板才能获得最大的辐照度，才可以达到最多的发电量。

    在曲面上选一点 $P$ 和观测方向 $\omega$，点 $P$ 在方向 $\omega$ 上的辐亮度（radiance）<Cite references={M} cite_items={[ { condition: 'PBRT', label: 'equation', locator: '4.3' } ] }/><Cite references={M} cite_items={[ { condition: { filter: m => m["collection-title"]?.includes('CS 184') && /Lecture/.test(m.title) && /Radiometry/.test(m.title) }, label: 'page', locator: '33' } ] }/>
    $$
    L_"e" (P,\omega) = "d"E_("e"\perp) (P,\omega)/"d"\omega = "d"^2 \Phi_"e" (P,\omega)/("d"A cos\theta"d"\omega)
    $$
    $"d"^2 \Phi_"e" (P,\omega)$ 代表包含点 $P$ 的面积元 $"d"A$ 沿方向 $\omega$ 附近的一小块立体角 $"d"\omega$ 传输的辐射功率。

    理想条件下，设点 $P_1$、$P_2$ 分别位于面积元 $"d"A_1$、$"d"A_2$ 上，且这两个面积元的距离为 $r$。考虑一束沿 $P_1$ 指向 $P_2$ 的方向（记为方向 $\omega$）传播的稳恒电磁辐射。由能量守恒定律，这束辐射传输给 $"d"A_1$ 和 $"d"A_2$ 的功率相同，记为 $"d"^2 \Phi_"e"$。设锐角 $\theta_1$、$\theta_2$ 分别为面积元 $"d"A_1$、$"d"A_2$ 在点 $P_1$、$P_2$ 处的法向量与传播方向 $\omega$ 的夹角。于是
    $$
    L_"e" (P_1,\omega)="d"^2 \Phi_"e"/("d"A_1 cos \theta_1 "d"\omega_1) \thinsp,\emsp L_"e" (P_2,\omega)="d"^2 \Phi_"e"/("d"A_2 cos \theta_2 "d"\omega_2)
    $$
    其中 $"d"\omega_1 $ 可借由 $"d"A_2$、$\theta_2$ 确定；$"d"\omega_2$ 可借由 $"d"A_1$、$\theta_1$ 确定，即
    $$
    "d"\omega_1="d"A_2 cos \theta_2/r^2 \thinsp,\emsp "d"\omega_2="d"A_1 cos \theta_1/r^2
    $$
    联立得
    $$
    "d"^2 \Phi_"e"=L_"e" (P_1,\omega)"d"A_1 cos \theta_1 "d"\omega_1=L_"e" (P_1,\omega) "d"A_1 cos \theta_1 "d"A_2 cos \theta_2/r^2
    $$
    $$
    "d"^2 \Phi_"e"=L_"e" (P_2,\omega)"d"A_2 cos \theta_2 "d"\omega_2=L_"e" (P_2,\omega) "d"A_2 cos \theta_2 "d"A_1 cos \theta_1/r^2
    $$
    于是
    $$
    L_"e" (P_1,\omega)=L_"e" (P_2,\omega)
    $$
    这告诉我们：在理想条件下观测同一稳恒电磁波源，辐亮度沿电磁辐射的传输方向不变。<Cite references={M} cite_items={[ { condition: { filter: m => m["collection-title"]?.includes('CS 184') && /Lecture/.test(m.title) && /Radiometry/.test(m.title) }, label: 'page', locator: '32' } ] }/>
  </section>

    ## 光度函数
    大量实验证明，人眼对不同波长的光的敏感度不同。而在光照充足与光照不足的环境下，人眼对同一波长的光的敏感度也不同<Cite references={M} cite_items={[ { condition: 'Rapport BIPM-2019/05', label: 'figure', locator: '1' } ] }/>。

    在明视觉（photopic）条件下，记（相对）光度函数（又名视见函数）<Cite references={M} cite_items={[ { condition: { filter: m => /光学/.test(m.title) && /新概念物理教程/.test(m.title) }, label: 'page', locator: '17' } ] }/>为 $V(\lambda)\in [0, 1]$，其中 $\lambda$ 为光的波长。在可见光的波长范围以外，取 $V(\lambda)=0$。

    暗视觉（scotopic）下的光度函数 $V\prime(\lambda)$ 定义类似。
  </section>

    ## 光通量、光出射度与照度
    光源可以同时发出多种波长的光。根据叠加原理，设一个光源的辐射通量的光谱分布为 $\Phi_("e",\lambda) (\lambda)="d"\Phi_"e" /"d"\lambda$。则其明视觉与暗视觉下的光通量（luminous flux）分别为
    $$
    \Phi_"v" = \int_0^+\infty  \Phi_("e",\lambda) (\lambda)K_"m" V(\lambda)"d"\lambda = K_"m"\int_0^+\infty  \Phi_("e",\lambda) (\lambda)V(\lambda)"d"\lambda
    $$
    $$
    \Phi_"v"^\prime = \int_0^+\infty  \Phi_("e",\lambda) (\lambda)K_"m"^\prime  V\prime(\lambda)"d"\lambda = K_"m"^\prime \int_0^+\infty  \Phi_("e",\lambda) (\lambda)V\prime(\lambda)"d"\lambda
    $$
    下标 $"v"$ 代表[光度学](https://zh.wikipedia.org/zh-cn/%E5%85%89%E5%BA%A6%E5%AD%A6)（Photometry）的物理量<Cite references={M} cite_items={[ { condition: 'Rapport BIPM-2019/05', label: 'section', locator: '2' } ] }/>。

    明视觉下和暗视觉下的最大光视效能
    $$
    K_"m" = K_"cd"  V(\lambda_"m")/V(\lambda_"a")\thinsp,\emsp K_"m"^\prime = K_"cd"  V^\prime  (\lambda_"m"^\prime)/V^\prime  (\lambda_"a")
    $$
    2019 年 $K_"cd"$ 被精确定义为 $683\thinsp"lm/W"$<Cite references={M} cite_items={[ { condition: { filter: m => /Mise en pratique for the definition of the candela/.test(m.title) }, label: 'section', locator: '2' } ] }/>。这意味着：将 1 W 的功率全部转化为 $f_"cd"=540\thinsp"THz"$ 的可见光，产生的光通量为 683 lm。又规定 $f_"cd"=540\thinsp"THz"$、频率为 $f_"cd"$ 的单色辐射在标准空气中的波长 $\lambda_"a"=555.017\thinsp"nm"$<Cite references={M} cite_items={[ { condition: { filter: m => /Mise en pratique for the definition of the candela/.test(m.title) }, label: 'page', locator: '3' } ] }/>。

    实验测得：在明视觉和暗视觉的条件下，当波长 $\lambda$ 为 $\lambda_"m"=555\thinsp"nm"$、$\lambda_m^\prime  = 507\thinsp"nm"$ 时，$V(\lambda)$、$V^\prime  (\lambda)$ 分别取得峰值。解得 $K_"m"\approx 683.002\thinsp"lm/W"$<Cite references={M} cite_items={[ { condition: 'Rapport BIPM-2019/05', label: 'equation', locator: '4' } ] }/>，$K_"m"^\prime  \approx 1700.13\thinsp"lm/W"$<Cite references={M} cite_items={[ { condition: 'Rapport BIPM-2019/05', label: 'equation', locator: '6' } ] }/>。

    单位面积发出或反射的光通量称为光出射度<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'luminous exitance') }, } ] }/>
    $$
    M_"v"="d"\Phi_"v"/"d"A
    $$
    单位面积接收的光通量称为照度<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'illuminance') }, } ] }/>
    $$
    E_"v"="d"\Phi_"v"/"d"A
    $$
    照度的常用单位为 $"lx"$，$1\thinsp "lx"=1\thinsp "lm/m"^2$。对于光出射度，对应的单位则直接使用 $"lm/m"^2$。
  </section>
  <section>
    ## 亮度与视亮度
    由叠加原理，设一个光源的辐亮度的光谱分布为 $L_("e",\lambda) (\lambda)="d"L_"e"/"d"\lambda$，则亮度（luminance，又名辉度）
    $$
    L_"v" = \int_0^+\infty  L_("e",\lambda) (\lambda)K_"m" V(\lambda)"d"\lambda = K_"m"\int_0^+\infty  L_("e",\lambda) (\lambda)V(\lambda)"d"\lambda
    $$
    亮度的常用单位为 $"nit"$，即 $"cd/m"^2$，其中 $1\thinsp"cd"=1\thinsp"lm/sr"$。

    理想条件下，光谱辐亮度 $L_("e",\lambda) (\lambda)$ 沿同一稳恒光源发出的光线保持不变，这时亮度也保持不变。这符合我们的日常经验：在晴天的户外，光照条件不变，当走近一面白墙时，白墙覆盖的可视范围变多了；远离这面白墙时，白墙覆盖的可视范围变少了；但这面白墙看起来并没有变得明显更亮或明显更暗。

    除了亮度以外，还有一个量叫视亮度（brightness）。两者的区别是：亮度是可以物理测量的光度量；视亮度则会受到背景、对比度、视觉适应及其余观察条件的影响。
  </section>
  <section>
    ## 测量
    测量照度的仪器称为照度计；测量亮度的仪器称为亮度计；用于测量光通量的仪器主要有积分球和分布光度计。

    在实践中，测量照度远比测量亮度方便；而测量亮度远比测量光通量方便，后者通常在专业的实验室完成测定。鉴于照度的测量成本相对低得多，主流智能手机基本上都配备了照度传感器。
  </section>
  <section>
    ## 应用：银幕亮度
    设某影厅采用一块面积为 $A$ 的银幕，其上每一点都总是满足光反射率<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'reflectance') }, } ] }/> $\rho=1$、光吸收率<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'absorptance') }, } ] }/> $\alpha=0$、光透射率<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'transmittance') }, } ] }/> $\tau=0$，且为理想漫反射面（Lambert 表面）<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'Lambertian surface') }, } ] }/>；投影和银幕的工程处理都尽量让银幕上各个位置的亮度均匀。

    银幕向前方（半球面 $\Omega$）反射光线。由 Lambert 余弦定律<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, `Lambert's cosine law`) }, } ] }/>，其亮度 $L$ 与观看角度无关。设观看位置与法线的夹角为 $\theta$，则该银幕总的光出射度与银幕亮度的关系是
    $$
    M=\int_\Omega  L cos \theta "d"\Omega  \emsp"s.t.  "\theta\in[0, 1/2 \pi)
    $$
    又<Cite references={M} cite_items={[ { condition: { filter: m => m["collection-title"]?.includes('CS 184') && /Lecture/.test(m.title) && /Radiometry/.test(m.title) }, label: 'page', locator: '16' } ] }/>
    $$
    "d"\Omega=sin\theta "d"\theta "d"\phi
    $$
    联立得
    $$
    M = \int_0^2\pi  \int_0^(1/2 \pi)  L cos\theta sin\theta "d"\theta"d"\phi = L\int_0^2\pi  "d"\phi  \int_0^(1/2 \pi) cos \theta sin \theta "d"\theta = L\int_0^2\pi  "d"\phi  \int_0^1 sin \theta "d"sin \theta = L\int_0^2\pi  (1/2 "d"\phi) = \pi L
    $$
    即<Cite references={M} cite_items={[ { condition: { filter: m => util.ieq(m["container-title"], 'E-ILV') && util.ieq(m.title, 'Lambertian surface') }, } ] }/>
    $$
    L=M/\pi
    $$
    记单台投影机的标称光通量为 $F$。若仅使用一台投影机，则需要满足
    $$
    F>=MA
    $$

    若使用 $N$ 台相同的投影机，并假设各台投影机均匀照亮整个银幕、输出的光通量可以线性相加，则每台投影机所需的光通量至少为
    $$
    F>=MA/N
    $$

    当然，在现实中，银幕无法将所有入射光全部反射；投影机实际输出的光通量也不一定总能达到标称光通量。因此，每台投影机实际所需的标称光通量通常大于 $F$；该结果只能作为理想下限，选型时应留有余量。

    另外，现代影厅常使用高增益银幕，使接近正对银幕的观众看到比银幕为 Lambert 体时更高的亮度，但代价是较大观察角下的亮度降低。一般地，银幕的增益系数不仅依赖观察方向，还依赖光的入射方向。这些涉及到较复杂的数学方法，本文不予讨论。

      ### 例
      放映亮度常用 $"fL"$ 表示。$"fL"$ 与 $"nit"$ 的换算关系为
      $$
      1\thinsp"fL"=(1/\pi)\thinsp"cd/ft"^2 \approx 3.42626\thinsp"cd/m"^2 = 3.42626\thinsp"nit"\thinsp,\emsp 1\thinsp"nit" \approx 0.291864\thinsp"fL"
      $$
      因此，$31\thinsp"fL" \approx 106.214\thinsp"nit"$，$22\thinsp"fL" \approx 75.3777\thinsp"nit"$。对于本节假设的理想 Lambert 银幕，$1\thinsp"fL"$ 的目标亮度对应 $1\thinsp"lm/ft"^2$ 的光出射度。因此，可以直接将以 $"fL"$ 表示的亮度数值作为以 $"lm/ft"^2$ 表示的光出射度数值计算。

      **例 1：** 某影厅的银幕尺寸为 $22\thinsp"m"\times 12\thinsp"m"$，要求 2D 影片的放映亮度为 $31\thinsp"fL"$，使用 2 台投影机。银幕面积和对应的光出射度分别为
      $$
      A=(22\thinsp"m")\times (12\thinsp"m")=264\thinsp"m"^2 \approx 2\thinsp 841.672\thinsp 350\thinsp"ft"^2,\emsp M=31\thinsp"lm/ft"^2
      $$
      因此，每台投影机所需的光通量为
      $$
      F>=MA/2=((31\thinsp"lm/ft"^2)(2\thinsp 841.672\thinsp 350\thinsp"ft"^2))/2 \approx 44\thinsp 046\thinsp"lm"
      $$
      理论书，每台投影机至少需要约 $44\thinsp 000\thinsp"lm"$ 的光通量。

      **例 2：** 某影厅的银幕尺寸为 $28\thinsp"m"\times 21\thinsp"m"$，要求 2D 影片的放映亮度为 $22\thinsp"fL"$，使用 2 台投影机。银幕面积和对应的光出射度分别为
      $$
      A=(28\thinsp"m")\times (21\thinsp"m")=588\thinsp"m"^2 \approx 6\thinsp 329.179\thinsp 325\thinsp"ft"^2,\emsp M=22\thinsp"lm/ft"^2
      $$
      因此，每台投影机所需的光通量为
      $$
      F>=MA/2=((22\thinsp"lm/ft"^2)(6\thinsp 329.179\thinsp 325\thinsp"ft"^2))/2 \approx 69\thinsp 621\thinsp"lm"
      $$
      理论上，每台投影机至少需要约 $70\thinsp 000\thinsp"lm"$ 的光通量。

      **例 3：** 某影厅的银幕尺寸为 $19\thinsp"m"\times 10\thinsp"m"$，要求 2D 影片的放映亮度为 $22\thinsp"fL"$，使用 1 台投影机。银幕面积和对应的光出射度分别为
      $$
      A=(19\thinsp"m")\times (10\thinsp"m")=190\thinsp"m"^2 \approx 2\thinsp 045.142\thinsp 979\thinsp"ft"^2,\emsp M=22\thinsp"lm/ft"^2
      $$
      因此，这台投影机所需的光通量为
      $$
      F>=MA=(22\thinsp"lm/ft"^2)(2\thinsp 045.142\thinsp 979\thinsp"ft"^2) \approx 44\thinsp 993\thinsp"lm"
      $$
      理论上，这台投影机至少需要约 $45\thinsp 000\thinsp"lm"$ 的光通量。
