本站的公式是使用 [UnicodeMath](https://unicodemath.org/) 书写的，并由 [UnicodeMathML](https://github.com/MurrayIII/UnicodeMathML)转换为浏览器支持的 [MathML](https://developer.mozilla.org/en-US/docs/Web/MathML)。

本章的推导过程的主要目的有：
- 解释概念或公式。
- 作为 UnicodeMath -> MathML 的真实内容样例，辅助检查解析、构建、页面排版与浏览器渲染。
