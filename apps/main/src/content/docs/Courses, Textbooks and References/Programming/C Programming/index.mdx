  许多专业课给出的代码示例是用 C / C++ 语言编写的。同时，如果想走嵌入式、内核、驱动等方向，对 C 语言的掌握是必不可少的。
    
  自 1972 年推出以来，C 语言已经发布了多个版本。1978 年 K&R C 问世后，C 语言在 1989 年首次标准化，得到的标准称为 ANSI C（C89）；随后 ISO C（C90)于 1990 年发布。此后，又陆续发布了 C95、C99、C11、C17（2018）和 C23（2024）版本。预计在 2029 年发布新的版本，非正式版本号 C2Y。学习 C 语言时，需要注意了解新版本的特性。

  不同的 C 编译器（compiler）对 C 标准的实现是有出入的，但常见的语法一般都遵循标准。

  2022 年 2 月 28 日，在 Linus Torvalds 的建议下，Arnd Bergmann 提交了将 Linux 内核编译模式从 GNU89 切换至 GNU11（含 GNU 扩展的 C11）的补丁<Cite references={page_reference} reference_ranges={reference_ranges} cite_items={[{ scope: ['reference'], filter: m => m.title === '[PATCH] [v2] Kbuild: move to -std=gnu11' }]}/>。同年 3 月 25 日，Linus 将相关改动合入主线，进入 Linux 5.18<Cite references={page_reference} reference_ranges={reference_ranges} cite_items={[{ scope: ['reference'], filter: m => m.genre === 'Git merge commit' }]}/>。
</section>
