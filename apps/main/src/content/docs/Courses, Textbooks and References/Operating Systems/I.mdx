A. Patterson《计算机组成与设计》<Cite references={course_material} reference_ranges={reference_ranges} cite_items={[ { scope: [ 'reference', 'text', 'en' ], filter: m => m.title === 'Computer Organization and Design MIPS Edition' && m.edition === 6, options: { count: 1 } } ]}/>（第 5 章和此书有部分重叠）的大部分章节，都是一遍就能看懂。期末考前几天我又看了一遍汤子瀛这本的前 7 章（后面几章当时我们不考），却又看懂了。汤的这本书还提到了 RTOS 概论等一些可以作为补充的知识，所以我留作参考；考研的同学也可以参考这本。

      中译版翻译质量达标，并且也被原书作者放上网了，不过主页不能直接进去，但可以被 Google 检索到。注意中译版没有随作者修订而更新，部分章节（如《SSD》及 Peter L. Reiher 添补的安全部分）缺失。
