关于教学质量：
- 记得我读本科期间（2020H1），教研室主任说：在硕博的培养方面，内地的计算机类专业已经不落后太多；内地与境外计算机名校的总体差距，主要体现在打基础的本科教学上。
- 而内地的计算机顶校与非顶校之间，本科教学质量的差距也是十分值得引起重视的。
- 一些发达国家的计算机类专业虽然总体有着更好的教学质量，但其实相当多的学校（包括某些名校）的计算机教学质量很一般。考虑此问题，本章遴选了优质的课程、教科书及参考资料，包括公开课。
- 通过充分利用信息时代以来最伟大的发明之一——互联网，大家也有机会享受（至少是一部分）以往只有顶校学生才可以享受到的资源。

关于本章的主要内容：
- 对于公开课，没有注明建议倍速，并不代表应当原速播放。可能是为了照顾基础不好的学生，许多大学在录制公开课时，都会将视频的播放速度降低。大家在播放的时候，一般都可以加速播放。
- 原 README 为各课程标注了 “建议开课学期” 一项，并假设一年 2 学期；但新版已将此项删去。后续将标注各课程所需的先修课程，届时大家可据此自行安排学习顺序。
- 在没有特殊说明的情况下，对于每门课，一般只需要选择其中 1 本教科书；学习指导书、习题集、其它参考资料则按需选择（不选、单选或多选）。我会持续为大家搜集更多免费/开放访问的资料。
- 由于时间关系，一些资料我尚未细读，我都临时将它们列为参考资料，暂未进行进一步的分类。

本项目的选书原则：
- 基准难度：荣誉 ECE（电气与计算机工程 / 电子与计算机工程）或 EECS（电气工程与计算机科学 / 电子工程与计算机科学）项目。
- 中英文都选。
- 优选免费 / 开放访问的资料；低价的次之。
  - 很多书会按区域发行不同版本。一般而言，北美版似乎是价格最高的；因而，除特殊情况外，会优选低价区的版本，比如全球版 / 国际版。
- 同一本书有时会以不同媒介发行，主要是打印版（纸质版）或数字版（电子版）。打印版又分为平装版（简装版）、精装版，英文站一般会称为 Paperback、Softcover、Hardcover。以这些不同媒介发行的版本原则上都会被记录，但本站目前暂未将它们全部显示——或者说，仅显示首选版本。
  - 首选版本的原则：
    - 如果有免费或开放访问电子书，则作为首选显示。
    - 如果可以购买未加密的电子书（允许带有用于防止盗版的隐写水印），则同样作为首选显示。Springer、InformIT（Pearson 旗下）等出版社常常提供此类电子书。
    - 如果只能购买加密的电子书（需要专门的软件进行阅读，且不可导出为未加密的 EPUB、PDF 等常用电子书格式），则首选纸质版。遗憾的是，绝大多数出版社通常都这样做，例如 Pearson、Wiley、McGraw-Hill、Cengage。
      - 这些专属软件已普遍具有相当强的反盗版机制，如侦测到使用自动化方法获取内容，它们会进行干扰或封禁。鉴于此，本项目在这些条件下优选纸质版。
      - 当然，也不排除你所在的高校或科研院所向这些出版社进行订阅，并可以凭此获得未加密电子书的情况。
    - 为了尽量压低价格，纸质书作为首选时，平装版或简装版一律优先，也就是先 Paperback，其次 Softcover，最后 Hardcover。
      - 不要忘记可以[委托网店将纸质书扫描为电子书](/tools-and-ideas/ebooks)。

需要强调的：
- 主推哪些书目为我个人观点。大家完全可以根据实际情况为自己选择书籍，当然也可以询问 AI。例如，有的书我没有选作教科书，只列作参考，但你充分考虑后认为这些书更适合自己用作教材，那么你在学习过程中也可以选择主要使用它们。
- 无论选教科书还是参考书，一般都不需纠结太多。
  - 首先，很多本科课程的内容都比较稳定，相应的教学方法也已成熟，很多书的差别并没有预想的那么大。
  - 其次，每个人的背景不同，很难保证一本书适合所有人。具体而言，可以说大概率总有一些内容是自己已经学过且尚未因长期不复习而重新变得生疏的，并且 / 或者另一些内容是自己反复学习也很难学懂的；后者对于数学等“硬课”尤其如此。就算在校期间十分幸运地遇到了这样的书目，以后工作也几乎必然不会总是这样走运——无论是教科书还是其它资料（官方文档等），出于不同的原因，比如作者或审校的疏忽或疲于应付上层不切实际的目标绩效，完全有可能会有多处存在不严谨或者干脆是错误或关键内容的遗漏。所以，我们不应强求总能获得完全匹配自己的前置知识与技能的书目；更应注重的是，在学习过程中逐渐培养信息检索乃至纠错的能力：学会在各种质量不一的信息中准确地找到所需的内容。
