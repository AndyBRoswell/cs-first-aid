    笔记本显示器

    Section titled “笔记本显示器”

    笔记本的屏幕尺寸一般在 13 英寸至 18 英寸之间。

    较厚、较大尺寸笔记本虽然更重，但更容易提升散热能力并增强可扩展性，因为主板可以做大，于是得以提供更多内存插槽、硬盘盘位、I / O 接口等。所以，如果打算购买笔记本，我推荐大家选择屏幕尺寸较大的：既观看方便，又获得更强的扩展性，过热降频的发生概率还更低，背着还有机会起到一些锻炼效果。

    使用 16:9 屏幕的笔记本一般不超过 17.3 英寸，使用 16:10 屏幕的笔记本一般不超过 18 英寸。超过 18 英寸的笔记本往往难以装入背包。

    每英寸像素（PPI）

    Section titled “每英寸像素（PPI）”

    通常，显示设备的规格会提供分辨率 𝑤×ℎ，单位均为像素；以及对角线尺寸 𝑑，单位为英寸（inch 或 ”）。于是，该显示器的 PPI 为

    𝜌=𝑤2+ℎ2𝑑

    根据视力估计所需的 PPI

    Section titled “根据视力估计所需的 PPI”

    记最小角分辨率（MAR）为 𝜃 arcmin，此时对应的视力（UCVA / BCVA）为 𝑉（小数记法），则

    𝜃=1𝑉

    设观看距离为 𝑑，像素间距（pixel pitch）为 𝑝，我们有

    tan⁡(12𝜃)=12𝑝𝑑

    即

    𝑝=2𝑑tan⁡(12𝜃)

    设单位长度为 𝑙，则像素密度

    𝜌=𝑙𝑝

    又有

    1arcmin=1180𝜋×160

    消去 𝜃，得

    𝜌=𝑙2𝑑tan⁡(𝜋21600𝑉)

    可见，所需的像素密度 𝜌 与视力 𝑉 及观看距离 𝑑 均有关。代入 𝑙=1in，则 𝜌 为 PPI。

    需要注意的是，这只是一个估计值。显示器的像素密度超过这个值，并不代表完全没有用：

    • 一般地，人眼对点、线、周期纹理、锯齿等的敏感度不同。
    • 子像素布局[1, Fig. 1]（如 RGB stripe、Pentile）会对实际感知产生可见影响。
    • 对比度、观看角度、软件层面的字体抗锯齿等因素也会产生较明显的影响。
    • 双眼视力常常优于单眼视力。

    高分屏是有用的

    Section titled “高分屏是有用的”

    对于一台 17.3” 笔记本，其显示比例多为 16:9。设其分辨率为 1080p，则其 PPI 为

    𝜌=(𝑤2+ℎ2𝑑)|𝑤=1920 px,ℎ=1080px,𝑑=17.3in≈127.34PPI

    类似地，当分辨率分别为 1440p 及 2160p 时，相应的 PPI 分别为 169.78 与 254.67。

    在观看距离为 𝑑=75cm 时，设视力为 1.0，则估算出所需的 PPI 为

    𝜌=(𝑙2𝑑tan⁡(𝜋21600𝑉))|𝑙=2.54cm,𝑑=75cm,𝑉=1.0≈116.43PPI

    然而，很多人的近视力（裸眼或矫正后）是优于 1.0 的。分别取视力为 1.25、1.6、2.0，可估算对应的 PPI 分别为 145.53、186.28、232.85。

    可见，显示器 / 显示屏分辨率大于 1080p 乃至达到 2160p，在许多场景中都是有用的。

    • 尤其是观看静态画面（网页、文档、代码、图片等）时，一块高分辨率的屏幕在细节上的提升更容易被注意到，比如即使字号很小也足够清晰的文字。这就使得我们能够：
      • 在同一屏幕同时阅读 2 页双列排版的论文的 PDF。
      • 在同一屏幕同时阅读多份源代码文件。
